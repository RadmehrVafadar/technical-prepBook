Solution code (user supplied; user reports running it successfully; run not directly observed by coach):
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        # [-2, 1, -3, 4, 2, 1, -5, 4]
        max_sum = float('-inf')
        cur_sum = 0
        left = 0
        for right in range(len(nums)):
            cur_sum += nums[right]

            max_sum = max(max_sum, cur_sum)
            while cur_sum < 0:
                cur_sum -= nums[left]
                left += 1

        return max_sum
Correctness explanation: User reasoned that a negative running prefix cannot improve any future subarray and should be discarded, and that max_sum must be updated before discarding it to preserve all-negative candidates.
