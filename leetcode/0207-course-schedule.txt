Final user-submitted code:
class Solution:
    def canFinish(self, numCourses: int, prerequisites: list[list[int]]) -> bool:
        preMap = {i:[] for i in range(numCourses)}
        for crs, pre in prerequisites:
            preMap[crs].append(pre)

        visited = set()
        def dfs(crs):
            if preMap[crs] == []:
                return True
            if crs in visited:
                return False

            visited.add(crs)
            for i in range(len(preMap[crs])):
                if not dfs(preMap[crs][i]): return False

            visited.remove(crs)
            preMap[crs] = []
            return True

        for crs in range(numCourses):
            if not dfs(crs): return False
        return True

Correctness explanation (assistant analysis of submitted code):
- preMap preserves every prerequisite relationship, with edges from a course to its prerequisites.
- visited represents the active recursion path, rather than all courses ever examined. Adding a course before exploring and removing it after successful exploration maintains this invariant.
- Reaching a course already on that path closes a directed cycle, so its requirements cannot be satisfied.
- An empty prerequisite list means either the course originally had no prerequisites or all its prerequisites have already been checked successfully.
- A course is marked safe by clearing its list only after every prerequisite returns True. A single False propagates immediately, which correctly implements the requirement that every prerequisite must be possible.
- Safe courses can be reused across branches without being mistaken for a cycle or repeatedly expanding their prerequisites.
- The outer loop checks every course, including disconnected components. Therefore the function returns True exactly when there is no directed cycle.
- On failure, some courses remain in visited. This is harmless because failure immediately propagates and the entire function returns False.

Time and auxiliary-space complexity:
- Let V = numCourses and E = len(prerequisites).
- Time: O(V + E). Each course's list is fully expanded at most once before being cleared; each prerequisite edge is processed at most once during that expansion. Building the map also costs O(V + E).
- Auxiliary space: O(V + E) for the prerequisite map, active-path set, and recursion stack. The stack and set can each reach O(V).
- Python implementation limitation: a sufficiently long prerequisite chain can exceed the interpreter recursion limit. No runtime failure was observed or reported in this session.
