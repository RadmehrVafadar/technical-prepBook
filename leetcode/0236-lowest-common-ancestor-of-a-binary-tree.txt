User explanation: DFS recursive traversal. Return the current target upward when found. Combine results from the left and right subtrees. If both results are non-null, the current node is the LCA; otherwise propagate whichever result exists.

User-provided solution code (Python 3):
class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        if not root:
            return None
        if root == p or root == q:
            return root
        l = self.lowestCommonAncestor(root.left, p, q)
        r = self.lowestCommonAncestor(root.right, p, q)
        if l and r:
            return root
        else:
            return l or r

Correctness explanation: The problem guarantees that p and q exist in the tree. An empty subtree returns None. The target-node identity check is written as root == p or root == q; reaching a target returns that node, including when it is an ancestor of the other target. Each recursive call returns a target found in its subtree or the LCA if both targets occur there. Non-null results from both child subtrees place the targets on opposite sides, making the current node their lowest common ancestor. With only one non-null result, that result is propagated upward.
Time complexity: O(n), where n is the number of tree nodes; each visited node is processed once.
Auxiliary-space complexity: O(h) for the recursion stack, where h is the tree height; O(n) in a skewed tree.
