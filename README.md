# Technical Prep Book

Personal coding-interview practice archive with versioned attempts, session notes, and feedback.

## Features

- Interview-only practice with minimal intervention.
- LeetCode attempts grouped by solving technique.
- Independent assessments and preserved retry history.
- Company question lists and Python practice snippets.

## Quick start

Open this repository in your coding agent and share a problem statement, screenshot, or code to begin an interview.
Browse the [attempt index](leetcode/README.md) for previous work by technique and problem.

## Repository layout

- [LeetCode attempts](leetcode/README.md) - versioned Python files and session records, grouped by technique.
- [Company question lists](company-questions/) - CSV lists for targeted preparation.
- [Standalone practice](practice/) - original Python exercises, including unfinished work.

Saved code and session records are historical evidence, so unfinished exercises and earlier revisions are retained.
