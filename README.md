# Technical Prep Book

Personal coding-interview practice archive with versioned attempts, session notes, and feedback.

## Features

- Interview-only practice with minimal intervention.
- LeetCode attempts grouped by solving technique.
- Independent assessments and preserved retry history.
- Company question lists and Python practice snippets.

## Quick start

Open this repository in your coding agent and share a problem statement, screenshot, or code to begin an interview.
Browse [saved attempts](leetcode/questions/) for previous work.
